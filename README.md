# Score d'appétence bancaire – Machine Learning

Ce projet consiste à développer un **modèle de score d’appétence client** permettant d’identifier les clients susceptibles de souscrire à un dépôt à terme dans le cadre de campagnes marketing bancaires.

L’analyse porte sur la préparation et l’exploration des données, le traitement des variables numériques et catégorielles, ainsi que la construction d’un pipeline de Machine Learning avec **Python et Scikit-learn**.

Plusieurs modèles de classification sont étudiés et comparés, notamment la **régression logistique, l’arbre de décision, AdaBoost et Random Forest**. Une attention particulière est portée au **déséquilibre de la variable cible**, avec une évaluation basée sur la précision, le rappel, le F1-score, la ROC-AUC et les matrices de confusion.

Le projet analyse également l’impact du **seuil de décision** afin d’adapter le modèle à l’objectif de ciblage des clients potentiellement intéressés.

### Technologies utilisées

* **Python**
* **Pandas / NumPy**
* **Scikit-learn**
* **Matplotlib / Seaborn**
* Machine Learning supervisé
* Classification binaire
* Prétraitement et pipelines
* Évaluation et optimisation des modèles
